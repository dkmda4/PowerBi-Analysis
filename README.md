# 📊 Power BI Portfolio

This repository contains a set of Power BI dashboards created to showcase my skills in data analysis, data modelling, DAX, and dashboard design.

Each dashboard focuses on a different type of analytical problem, demonstrating how Power BI can be used to support business decision-making, operational insight, and strategic analysis.



## 🧭 Dashboard Index

### 🌍 1) Global Risk and Resilience Overview

Focus: descriptive analytics and global comparison

<img width="1025" height="578" alt="Screenshot 2026-01-29 at 11 57 02" src="https://github.com/user-attachments/assets/85f2c12c-e305-40eb-9835-f6b68d9102f3" />


This dashboard provides a high-level view of environmental stress, economic resilience, and trade balance across 161 countries.

**Key capabilities:**

	•	Compare countries using multiple risk indicators
	•	Identify high-risk regions using rankings
	•	Explore the relationship between economic resilience and trade exposure
	•	Drill down into individual countries using interactive filters

**Skills demonstrated:**

	•	Data modelling across multiple datasets
	•	KPI design and aggregation
	•	Interactive dashboard layout
	•	Conditional formatting for risk analysis


### 💼 2) Trade, Resources and Vulnerability Analysis

Focus: analytical reasoning and segmentation

<img width="2331" height="1314" alt="Screenshot 2026-02-01 at 01 13 47" src="https://github.com/user-attachments/assets/c8e21448-5a93-4d1f-b4e2-75ba154ad4ab" />


This dashboard explores how resource dependency, supply chain disruption, and inflation influence a country’s trade vulnerability.

**Key capabilities:**

	•	Segment countries into vulnerability groups
	•	Identify outliers using scatter analysis
	•	Compare multiple risk drivers in one view
	•	Use DAX logic to classify and benchmark performance

**Skills demonstrated:**

	•	Advanced DAX logic and categorisation
	•	Analytical segmentation
	•	Scatter and decomposition analysis
	•	Custom tooltips for contextual insight


### 📈 3) Population Growth and Trend Analysis

Focus: time series and forecasting-style insight

This dashboard analyses population growth over time to identify fast-growth and stable-growth countries.

**Key capabilities:**

	•	Track population changes by year
	•	Rank countries by growth rate
	•	Compare indexed growth (base year = 100)
	•	Drill through to country-level trend views

**Skills demonstrated:**

	•	Time-series analysis
	•	Dynamic measures
	•	Trend interpretation
	•	Drill-through and page navigation
